// 重新复习的点：
// 模式字符串：

// "r" ：只读，文件必须存在
// "w" ：只写，不存在则创建，存在则清空
// "a" ：追加写，末位写入
// "r+" ：读写，文件必须存在
// "w+" ：读写，清空或新建
// "a+" ：读+追加写，文件不存在则创建

表格
函数	功能
fgetc(FILE*)	读取一个字符，返回 int（EOF 表示结束）
fputc(int, FILE*)	写入一个字符
表格
函数	功能
feof(FILE*)	检测是否到达文件末尾（注意要读一次后判断）

bat:
g++ -finput-charset=UTF-8 -fexec-charset=UTF-8 io.cpp -o io.exe
-finput-charset=UTF-8：告诉编译器 源文件本身 是 UTF-8 编码
-fexec-charset=UTF-8：告诉编译器 生成的字符串常量 使用 UTF-8 编码
