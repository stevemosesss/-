**核心改造**

1. **Token 二元组结构体数组**（替代旧的纯字符串数组）：
   ```c
   typedef struct { int tokenClass; char seman[64]; } Token;  // 种别编码 + 单词值
   typedef struct { Token* items; int size, capacity; } TokenList;
   ```
   （C++ 中 `class` 是关键字，字段用 `tokenClass`）

2. **逐字符扫描，不再依赖空格**——这是旧版最大痛点（原来 `2;` 会粘成一个词）：
   - 字母/下划线开头 → 连续读字母数字下划线，查关键字表命中则 class=1–10，否则标识符=11
   - 数字 → 正整数/零=12；小数点后有数字才识别为正实数（如 `3.14`），否则点号独立成 token=36（正确处理 `a.b`）
   - 运算符双字符预读：`>=19 <=21 !=22 ==23 &&25 ||26`，单字符 `+13 -14 *15 /16 %17 >18 <20 !24 =28`
   - 括号 `[29 ]30 (31 )32 {33 }34`、逗号 27、分号 35、换行 37（存为可见 `\n`）、`#`=38
   - 无法识别的字符报词法错误、进程返回非零退出码（不中断后续扫描）
